## Deploy with AWS Amplify

This is a static HTML site; no framework build or backend is required. The repository includes an `amplify.yml` build specification.

1. Push the repository to GitHub.
2. In the [AWS Amplify console](https://console.aws.amazon.com/amplify/), choose **Create new app** and connect the GitHub repository and deployment branch.
3. Keep the app root at the repository root and use the provided build settings.
4. Start the deployment. Amplify will provide a hosted URL when the build completes.
